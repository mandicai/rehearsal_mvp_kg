# Pinned to versions verified working locally (see the Dockerfile for the
# deployed build) - torch/sentence-transformers/spacy/docling are all prone
# to breaking across versions, so this isn't just tidiness. torch/
# torchvision specifically must be installed together from the same
# CPU-only index (see the Dockerfile's own comment) - a plain
# `pip install -r requirements.txt` here (e.g. for local dev) pulls both
# from the default PyPI index instead, which works fine on its own but
# isn't what's actually deployed.
#
# Also requires ffmpeg on PATH (used by premiere_bridge.py/animate_llm.py)
# - installed in the Dockerfile, `brew install ffmpeg` locally.
#
# LibreOffice (the `soffice` binary, for ingest/pptx_render.py's PPTX
# rendering) is NOT installed in the deployed Dockerfile - that route isn't
# wired to any button on the current live pages (index.html/
# storyboard.html only), presenter-view.html having been removed. Add
# `apt-get install libreoffice` back to the Dockerfile if that feature is
# revived; `brew install --cask libreoffice` locally.
