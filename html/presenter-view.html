4. Simulate Audience

Simulates ~3 independent audience members answering an open-ended question for each takeaway, at the point in the presentation where it first becomes assessable, and estimates how understanding builds slide by slide (inspired by Bayesian Knowledge Tracing).

This bar is a Bayesian-Knowledge-Tracing-style estimate of the probability that a member of this audience actually understood this takeaway by the time it was covered. It starts from a 30% prior, is updated by grading 3 simulated audience members' answers to a comprehension question grounded only in the transcript they'd have heard so far (no lookahead), and - if this takeaway has a prerequisite - is further reduced if that prerequisite wasn't well understood either.
